# Sözlük & Terimler

## Marka / kurumsal
| Terim | Anlam |
|-------|-------|
| **UGR** | Marka monogramı / öneki. |
| **UGR Ölçüm ve İklimlendirme** | Kısa kamuya tanıtım adı (nav/footer lockup). |
| **F-Gaz** | Florlu sera gazları (soğutucu). Yönetmelik kapsamında ölçüm/dolum yetki ister. |

## Sektör terimleri
| Terim | Anlam |
|-------|-------|
| **R32 / R410A** | Yaygın soğutucu gazlar (AC-verse). F-Gaz kapsamında.
| **BTU** | Soğutma kapasite birimi; odanın seçiminde belirleyici. |
| **İç ünite** | Bina içine kurulan ünite (evaporatör). |
| **Dış ünite** | Dışarıdaki ünite (kondanser). |
| **Kondanser** | Dış ünitede ısı atan boru grubu. |
| **Evaporatör** | İç ünitede ortamı soğutan boru grubu. |
| **Drenaj / drenaj tavası** | Yoğuşma suyu tahliye hattı / toplama tavası. |
| **Vakumlama** | Boru hattındaki nem/hava alma işlemi (montajda). |
| **İnverter** | Devir ayarlı (daha verimli) kompresör teknolojisi. |

## Tasarım (Steep) terimleri
| Terim | Anlam |
|-------|-------|
| **Signifier / Sohne** | Design sistemin display serif / body sans fontları; kodda Source Serif 4 / Inter ile temsil edilir. |
| **Blush Peach** | `#fbe1d1` vurgu yüzeyi — sayfada en fazla 1. |
| **Sienna Brown** | `#5d2a1a` — şeftali üstünde metin + grafik çizgisi. |
| **Yüzen artefakt** | Gölgeli, üst üste binen beyaz ürün UI kartı. |
| **Ghost / pill** | İnce kenarlıklı / tam yuvarlak buton stilleri. |

## Mimari terimleri
| Terim | Anlam |
|-------|-------|
| **SSG** | Build'de önceden üretilen statik HTML (blog/hizmet detay). |
| **dynamicParams = false** | SSG'de bilinmeyen slug'a `notFound()` döndürür. |
| **`params` Promise** | Next 16'da `await` edilmesi gereken dinamik rota parametresi. |
| **`render` prop** | Base UI / shadcn'de `asChild` yerine kullanılan eleman-merger (`render={<Link/>}`). |
